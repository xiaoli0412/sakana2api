POST /v1/chat/completions

OpenAI 兼容对话补全。支持流式 (SSE) 与非流式、多轮工具调用、图像与文件附件、深度思考 (reasoning_content) 与联网检索 (citations)。

usage 计量:prompt_tokens 含组装后完整上下文(系统注入+全部附件文本+光学压缩页按像素折算),CJK 按每字符约 1 token 估算;total_tokens = prompt + completion。

curl -X POST http://your-server:8787/v1/chat/completions \ -H "Authorization: Bearer sk-sak-..." -H "Content-Type: application/json" \ -d '{"model":"sakana","stream":true,"messages":[{"role":"user","content":"你好"}]}'
Responses 风格

与 Chat Completions 同构;conversation_id 响应字段用于多轮粘性(同账号同上游会话)。流式尾 chunk 携带完整 usage(choices 为空数组,OpenAI 规范)。

Messages (Anthropic 兼容)

/v1/messages 支持 Anthropic 工具协议;usage 映射为 input_tokens/output_tokens。Gemini 客户端走 /v1beta/models/{model}:generateContent。
