🚀 客户端接入指引 (OpenAI SDK 兼容)
🐍 Python (openai >= 1.0)
from openai import OpenAI

client = OpenAI(
    api_key="sk-sak-xxx", # 或留空(开放模式)
    base_url="http://localhost:8787/v1"
)

response = client.chat.completions.create(
    model="sakana-namazu",
    messages=[{"role": "user", "content": "你好"}],
    stream=True
)
for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")

📖 API 接口与交互文档
POST /v1/chat/completions 标准对话接口 (兼容 OpenAI)

支持标准流式（SSE）与非流式调用，支持思考链（reasoning_content）、多模态图片、文本附件、联网搜索以及多轮对话自动上下文粘性绑定。

{ "model": "sakana-namazu", // 可选: sakana-namazu, sakana-fugu, sakana-namazu-polite, sakana-namazu-osaka "messages": [ { "role": "system", "content": "You are a helpful assistant." }, { "role": "user", "content": "帮我写一首关于海洋的诗" } ], "stream": true }
POST /v1/responses OpenAI 简化版 Responses 接口

简化调用参数，直接传入 input 与 instructions，自动转换为标准上下文。

{ "model": "sakana-namazu", "input": "请帮我规划一个为期三天的东京旅行路线", "instructions": "你是一位专业的旅行规划师", "stream": false }
POST /v1/messages Anthropic Claude 兼容接口

兼容 Claude 风格请求结构，自动转换为 Sakana 协议并返回 content_block_delta 格式流。

GET /v1/models 模型列表

返回网关支持的全部模型矩阵与描述信息。
